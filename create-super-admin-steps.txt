Create the first super-admin (run once after deploy)
====================================================

Run this once (safe in CI/CD — DB must be migrated + seeded first):

    BOOTSTRAP_ADMIN_EMAIL="superadmin@veratechsolutions.example" \
    BOOTSTRAP_ADMIN_PASSWORD="<strong-password>" \
    uv run python scripts/bootstrap_platform_admin.py

This just creates the operator — no terminal QR.

The operator then sets up 2FA in the browser:
  1. Go to /platform/login, enter email + password.
  2. The page shows a QR code -> scan it with an authenticator app.
  3. Enter the 6-digit code -> logged in, 2FA is now set up.
  4. Save the recovery codes shown once.

Notes:
- MFA is required for super-admins (no password-only mode).
- Safe to re-run (no-op if a super-admin already exists).
- Next logins ask only for the 6-digit code.
